## 🚀 Get Started

Deploy TakeSlice Self-Hosted on your own infrastructure using Docker.

### 1. Clone the repository

```bash
git clone https://github.com/takeslice/takeslice-selfhosted.git
cd takeslice-selfhosted
```

### 2. Configure your environment

```bash
cp .env.example .env
```

Set a secure PostgreSQL password and review the environment configuration.

### 3. Start TakeSlice

```bash
docker compose up -d --build
```

### 4. Complete setup

Open:

`http://localhost:3000/setup`

Follow the first-run wizard to configure your business, admin account, and affiliate program.

For complete instructions, see the [installation documentation](https://github.com/takeslice/takeslice-selfhosted#quick-start).

## 🤖 Integrate with AI

TakeSlice Self-Hosted makes integrating an affiliate program into your existing application easier.

The built-in AI Setup assistant generates integration instructions tailored to your installation.

Simply:

1. Open the TakeSlice dashboard.
2. Navigate to **AI Setup**.
3. Generate and copy your integration prompt.
4. Paste it into Cursor, Claude Code, Codex, or another coding agent.
5. Follow the integration instructions and verify your referral tracking.

**No npm package required. No mandatory cloud account. Your infrastructure, your control.**
